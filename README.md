# practice-BigEvent

A Spring Boot practice project built while learning backend development.

## Tech Stack

- Java 23
- Spring Boot 4
- Spring MVC
- MyBatis
- MySQL
- JWT
- Hibernate Validator
- PageHelper

## Features

### User Module
- ✅ User registration
- ✅ User login (JWT authentication)
- ✅ Get user information
- ✅ Update user profile
- ✅ Update avatar
- ✅ Update password

### Category Management

- ✅ Create category
- ✅ List categories
- ✅ Get category details
- ✅ Update category
- ✅ Delete category

### Article Management

- ✅ Create article
- ✅ Paginated article query with dynamic filtering
- Article details
- Update article
- Delete article

### Authentication
- JWT authentication
- Login interceptor
- ThreadLocal user context

### Validation
- Hibernate Validator
- Global exception handling
- Validation groups
- Custom validation annotation

### Pagination
- PageHelper integration
- Generic PageBean response

Currently under development.
