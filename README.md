# practice-BigEvent

A full-stack learning project featuring modern Java backend development and web technologies.

## Tech Stack

- Java 23
- Spring Boot 4
- Spring MVC
- MyBatis
- MySQL
- Redis
- Alibaba Cloud OSS
- JWT
- Hibernate Validator
- PageHelper

## Features

### User Module
- ✅ User registration
- ✅ User login (JWT authentication)
- ✅ Get user information
- ✅ Update user profile
- ✅ Update avatar
- ✅ Update password

### Category Management
- ✅ Create category
- ✅ List categories
- ✅ Get category details
- ✅ Update category
- ✅ Delete category

### Article Management
- ✅ Create article
- ✅ Paginated article query with dynamic filtering
- ✅ Get article details
- ✅ Update article
- ✅ Delete article

### File Upload
- ✅ Upload images to Alibaba Cloud OSS
- ✅ Generate unique filenames using UUID
- ✅ Return public file URL

### Authentication & Security
- ✅ JWT authentication
- ✅ Redis-based token validation
- ✅ Automatic token invalidation after password update
- ✅ Login interceptor
- ✅ ThreadLocal user context

### Validation
- ✅ Hibernate Validator
- ✅ Global exception handling
- ✅ Validation groups
- ✅ Custom validation annotation

### Pagination
- ✅ PageHelper integration
- ✅ Generic PageBean response
